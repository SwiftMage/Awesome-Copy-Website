Install via Homebrew

Install Awesome Copy with a single command. Choose the stable release or opt into the beta channel.

Stable Recommended

The latest stable release of Awesome Copy.

brew install kindparkllc/tap/awesome-copy
Beta Beta

Early access to new features. Beta builds are updated frequently and may contain bugs.

brew install kindparkllc/tap/awesome-copy-beta
Upgrading

To get the latest version after it's already installed:

brew update && brew upgrade kindparkllc/tap/awesome-copy
brew update && brew upgrade kindparkllc/tap/awesome-copy-beta

Don't have Homebrew? Install it at brew.sh.
