Version 5.11 February 2, 2026

New Features

Last Copied Text in Menu Bar
New option to show the last copied text in the menu bar after the app icon for quick reference.
New Menu Bar Icon Animations
Added Fly Up and Blink animation options - more subtle and pair nicely with the new menu bar text option.
App Launch Authentication
Require a password or Touch ID to launch the program, protecting users with sensitive clipboard data.
Security & Privacy Settings Section
New dedicated Security & Privacy section in settings for better organization of privacy-related options.
Passwords Smart Filter
New smart filter to show all password entries in clipboard history, making it easy to find concealed items from password managers.
URL Tracking Data Removal
Strip tracking data out of copied URLs, either automatically or manually. Configure in the Security & Privacy settings.
Copy Image File Path
New 'Copy Path' option in the image right-click menu to quickly copy the file path.

CleanShot X & Shottr Support

CleanShot X Screenshot Names
Screenshots taken with CleanShot X now display proper names.
Annotate in CleanShot X
New right-click option to open images in CleanShot X for annotation.
Pin to Desktop & Quick Access Overlay
New right-click options to pin images to the desktop or open in CleanShot X's quick access overlay.
Open in Shottr
New right-click option to open an image directly in Shottr for annotation and editing.

Changes

Horizontal Snippet Single-Click Copy
Clicking a snippet in horizontal view now copies and selects immediately instead of requiring a double-click.
Single-Click Selects Item
When 'Double-Click Action' is set to copy, a single click now selects the clipboard item for preview and context menu access.
Adaptive Header Buttons
Vertical list header buttons dynamically adjust to fit when the list gets narrow.
Screen Edge Gap Removal
'Distance from screen edge' setting can now be set to fully remove the gap between the list and the screen edge.
Cleaner Dynamic Island
Snugged up the Dynamic Island window around the content box for a tighter appearance.
&Command;+K Opens Context Menu
Press ⌘+K to bring up the same context menu as right-clicking a clipboard item.

Bug Fixes

Fixed Auto-Hide Delay
Auto-hide delay timer was waiting too long before hiding the window.
Fixed Startup Crash
Fixed a crash that could occur at startup.
Smoother Horizontal to Floating Transition
Changing from horizontal to floating list in settings now works more smoothly.
Fixed Item Clipping
Normal and card view items were getting cut off in certain configurations.
Fixed Horizontal Keyboard Navigation
Fixed keyboard navigation jumping scroll position to the edge.
More Fixes
Fixed cover dock after screen lock, faster mouse wheel scrolling, fixed smart search background on older macOS, fixed copy preview password masking, and fixed copy preview getting stuck open.
Version 5.07 January 10, 2026

New Features

Collections View
A powerful new way to browse and organize your clipboard history. Access it from the menu bar app's right-click menu.
App Object Support
Optional support for app objects like documents, slides, spreadsheets, Figma designs, and more.
Undo Deletion
Accidentally deleted a clipboard item? Press Command+Z to undo deletion of up to 10 items.
Text Selection Popup
A floating Copy/Cut/Paste toolbar appears near your cursor when you select text in any app. Optional feature, disabled by default.
Pinned Items Position Setting
New setting to control whether pinned items move to the top of the list or stay in their original position.
Auto-Show on Copy
Automatically show the clipboard history after copying, then dismiss it after a configurable delay unless you interact with it.
Settings Search
New search field in settings makes it easy to find any setting quickly.

Changes

Improved Card Pin Icon
Changed card style pin indicator to a blue filled pin for better visibility.
Pinned Smart Category
Added 'Pinned' to smart categories to quickly view all your pinned clipboard items.
Mission Control Exclusion
AwesomeCopy windows are now excluded from Mission Control for a cleaner desktop.

Copy Preview Improvements

Improved Drop Zone
Drop zone now shows 'Drop here' text with consistent sizing for single and multiple files.
Click File Stack to Copy
Clicking a file stack copies the content to clipboard and history.
Hover Delay for Peek
Customizable hover time delay before opening the peek window to prevent accidental activations.

Bug Fixes

Multiple Fixes
Fixed application support folder duplication, history/snippets toggle button, video thumbnails, Quick Paste theme contrast, and various crash fixes.
Version 5.06 January 5, 2026

Major Features

Clipboard Vault
Save clipboard history items as persistent files with automatic duplicate detection. Your important clips are always safe.
Snippets iCloud Sync
Snippets now sync via iCloud! Create, edit, and delete snippets on macOS and they automatically appear on your iOS devices.

Dynamic Island Copy Preview

Peek & Pin Modes
Copy any file or image to see a quick preview near your notch. Click to pin it open and start collecting files.
File Shelf
Pinned windows become a collection shelf - keep copying and files stack up visually. Drag the entire stack to drop all files at once.
Shake to Open
Select a file and shake it to instantly open the preview.
Notch Hover
Mouse over the notch to reveal the preview; move away to close it.

Privacy & Security

Clear History on Screen Lock
Automatically clears clipboard history when you lock your screen.
Clear History on Sleep
Automatically clears clipboard history when your Mac goes to sleep.

Settings & Customization

Footer Icon Customization
Include/exclude every icon in the footer for total customization of your clipboard interface.
Liquid Glass Sticky Notes
Sticky notes now have beautiful Liquid Glass pop up window chrome controls for a modern look.

Drag & Drop Improvements

Smart Text Field Dropping
Dragging text into text fields now pastes directly instead of creating a text file. Hold Shift for plain text, Option for .txt files.

Bug Fixes

Multiple Fixes
Fixed Russian settings sidebar, list auto-scroll, space bar preview trigger, scroll performance, delete selection behavior, Clear theme Quick Paste, start at system startup, paste as plain text, and Escape key behavior for translate/preview windows.
