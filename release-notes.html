Version 5.15 March 7, 2026

New Features

Conceal Clipboard Entries
Selectively conceal clipboard entries and reveal them with your system password or Touch ID. Also works with auto-concealed password entries.
Hot Corners
New hot corners feature to show or hide the clipboard list by moving your mouse to the corner of the screen.

Changes

Unified Normal & Card Style Codebase
Consolidated the normal style into the same codebase as card style. This brings their behavior and styling more inline — bug fixes and improvements in one now apply to both.
Card Style Categories & Smart Categories
Added category support for the card list style. New setting to enable or disable smart categories.
Title Bar & Expansion Window
More customization for list item title bars. Image/text expansion window now points to the edge of the clipboard item instead of the center, which blocked content.
Collections View Drag & Drop
Added drag and drop support for items in the Collections View into the sidebar folders.
Show/Hide Animation
The list now fades in and out when shown or hidden, adding a touch of class.

Bug Fixes

Fixed Selection Border Clipping
Fixed selection border getting clipped in normal style.
Omniscient View Click Settings
Omniscient view now respects the single/double click settings.
Fixed Expansion Window
Fixed bug that caused the expansion window to stay open.
Version 5.14 February 27, 2026

New Features

Paste Stack
Added a new Paste Stack feature.
Quick Paste for Menu Bar Apps
Enabled quick paste support for menu bar apps.

Changes

Customizable Title Bar Buttons
Added the ability to choose and reorder all title bar buttons for clipboard history items.
Settings Reordering & Defaults
Reordered behavior settings to move single/double click to the top. "Distance from screen edge" now goes up to 100. Changed default auto-hide delay from 5.0 to 3.0 seconds. Changed "Save settings in Keychain" default to off for new users.
Older macOS Visual Improvements
Older macOS versions without liquid glass support now have a tinted list background with added blur (material) to provide contrast.
Copy Animation Setting
Added a setting to enable or disable copy animations in the normal list.

Bug Fixes

Fixed Double Copy on Click
Fixed issue with double copying on click.
Older macOS Title Bar Fixes
Fixed card title bar being hidden during scrolling on older macOS versions. Fixed clicking title bar buttons resulting in a copy on older macOS versions.
Normal List Copy & Animation
Fixed normal list slow copy and animations.
Mouse Click Drag Fix
Fixed issue in the normal list where moving the mouse slightly while clicking would trigger a drag instead of a copy.
Collection View Selection
Fixed macOS Sequoia and older bug where selecting items in Collection View was erratic.
Scrolling Width Glitch
Fixed scrolling issue where scrolling could sometimes trigger a very slight widening of clipboard item's display.
Update Check & Copy Preview
Fixed update check system waiting too long (24 hours) before checking. Fixed copy preview window staying open after a copy.
Version 5.13 February 24, 2026

Bug Fixes

Buttery Smooth Scrolling
Get your popcorn ready — scrolling is buttery smooth now. Changed mouse wheel scrolling to use native scrolling behavior which is less laggy and just nicer in general.
Normal View Text Wrapping
Normal view text now wraps to show multiple lines even if there are no hard returns in the text.
Smart Filters in Horizontal List
Fixed bug where smart filters were not showing up in the horizontal list.
Search Filter Keyboard Navigation
Using keyboard arrow keys in the search filter box now controls the cursor position with left/right and the smart filter with up/down.
Restored Card Title Option
Restored the option to remove the card title which got removed by accident.
Search Bar Suggestion List
Fixed issue with the search bar suggestion list and arrow keys not traversing the list correctly.
Menu Bar Icon Focus
Clicking the app's menu bar icon now not only shows the list, but gives it focus so keyboard shortcuts and navigation will work immediately.
Context Menu Shaking
Fixed clipboard history right-click menu items shaking slightly when the menu first opens.
Rich Text Color Preservation
Rich text color is now preserved by adjusting the clipboard item's background color. You'll see dark backgrounds when text color is light, and light backgrounds when text color is dark.
Open Bar Position Fix
Fixed bug with the open bar causing it to not move to its closed position.
Double-Click to Copy
Fixed double-click to copy not working when the single-click action was set to select.
Memory Improvements
A handful of memory improvements for better overall performance.
Version 5.12 February 10, 2026

New Features

Update Notifications
Update notifications now show in the list when available. A new setting controls whether updates are checked automatically.
Safe Mode
Hold the Option key while starting the app to enter Safe Mode, with options to save settings before restoring them to factory defaults.
~60 New Transformations
Approximately 60 new text transformations added to the transformation library.
Trash in Collection View
New Trash section in Collection View for reviewing deleted items, with an option to purge cached undo items.
Detail Panel
New Detail Panel expands the vertical list to show a fixed preview and item metadata.

Changes

Liquid Glass Effect
Clipboard items now flow under the header and footer of the vertical list with a liquid glass effect. Also applied to selected tab icons (history/snippets) replacing the blue circle indicator.
Footer & Header Improvements
Reduced vertical list footer height. Footer now has even spacing, center-aligned and uniform icon sizes, with colored icons made optional. Top menu icons are now uniform in size and weight.
Card & List Style Updates
Added option to fit images into cards instead of filling them. New copy animation replaces the green flash across all list styles. Added source app and image previews to minimal list, plus a "Super compact" option.
Settings Improvements
Settings sidebar now always starts at the top with a scroll bar so the window can be smaller. Moved "max text preview lines" into the advanced section. SF Symbol support added for snippet folder icons.
UI Polish
Snippets view icons now match the history list in size and weight. Fixed snippet folder scroll bar overlay. Clicking the preview icon a second time now closes the preview. Improved popup preview window on hover.

Bug Fixes

Scrolling & Navigation Overhaul
Reworked scrolling for better performance. Fixed display refresh bug when navigating with up/down keys, list not following keyboard selection, and keyboard navigation skipping multiple items.
Link Previews & Performance
Reworked link preview loading to be faster and prevent links from not loading correctly. Fixed significant lag when copying/pasting directly to an application. Improved Collection View scrolling performance.
Window & Focus Fixes
Fixed the app auto-opening the history window and stealing focus ~15 seconds after launch. Fixed copy preview showing when disabled. Fixed multi-screen notch issue opening preview on wrong screen. Fixed quick paste window not scrolling with keyboard selection.
Appearance & Startup
Fixed light/dark mode switching when "System" appearance is selected. Added app settings/defaults validation on startup to help prevent issues that prevent the app from starting.
French Localization
Fixed extra characters in French translation, corrected French shortcuts for "Copy with addition" and "Reopen last copied item", fixed "Browse" button opening an inaccessible App Store page in France, and added 345 missing French translations.

More Fixes
Fixed cover dock after screen lock, faster mouse wheel scrolling, fixed smart search background on older macOS, fixed copy preview password masking, and fixed copy preview getting stuck open.

Less common image file types (AVIF, HEIF, WebP, TIF, ICNS) now show image previews correctly.
