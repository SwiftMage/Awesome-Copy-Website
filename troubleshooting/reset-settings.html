Something Not Working Correctly

Most issues in Awesome Copy are caused by a misconfigured setting. Follow these steps to back up your settings and reset them.

1

Back Up Your Settings

Before making any changes, export a backup of your current settings so you can restore them later if needed.

Open Awesome Copy > Settings > Import/Export > App Settings > Export.

Keep this file safe. If the reset fixes your issue, you can selectively re-apply settings from your backup. If it doesn't, you can import the backup to restore everything.

2

Reset Your Settings

The issue is most likely caused by a setting. You have two options: a full reset that wipes everything, or a partial reset that only clears internal state while keeping your preferences.

Option A: Full Reset

If you don't care about your current settings and want a clean slate, run this single command in Terminal. Restart the app after the command completes.

defaults delete com.evan.AwesomeCopy

This will erase all Awesome Copy settings. The app will behave as if it was freshly installed. Make sure you've completed Step 1 first so you have a backup.

or
Option B: Partial Reset (Keeps Your Preferences)

This option resets window positions, internal state, and UI states without touching your personal preferences. You can copy and paste all of these commands into Terminal at once. Restart the app after the commands complete.

# 1. Backup first (saves to Desktop)
defaults read com.evan.AwesomeCopy > ~/Desktop/AwesomeCopy-defaults-backup-$(date +%Y%m%d-%H%M%S).plist

# 2. Reset window positions and frames
defaults delete com.evan.AwesomeCopy "NSWindow Frame ClipboardHistoryWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame SettingsWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame AboutWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame WhatsNewWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame OmniscientWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame QuickPasteWindow"
defaults delete com.evan.AwesomeCopy "NSWindow Frame AIAnalysisWindow"

# 3. Reset window position/dock related state
defaults delete com.evan.AwesomeCopy windowDockPosition
defaults delete com.evan.AwesomeCopy copyHistoryDockPosition
defaults delete com.evan.AwesomeCopy lastWindowPosition
defaults delete com.evan.AwesomeCopy savedWindowFrame

# 4. Reset internal state
defaults delete com.evan.AwesomeCopy lastSyncDate
defaults delete com.evan.AwesomeCopy lastClipboardChangeCount
defaults delete com.evan.AwesomeCopy selectedCategoryFilter
defaults delete com.evan.AwesomeCopy sequentialPasteIndex
defaults delete com.evan.AwesomeCopy lastSelectedItemId

# 5. Reset UI expansion/visibility states
defaults delete com.evan.AwesomeCopy detailPanelVisible
defaults delete com.evan.AwesomeCopy categoryExpansionState
defaults delete com.evan.AwesomeCopy folderExpansionState

# 6. Reset popover/panel states
defaults delete com.evan.AwesomeCopy popoverIsShowing
defaults delete com.evan.AwesomeCopy lastPopoverSize

# 7. Restart the app to apply changes
killall AwesomeCopy 2>/dev/null
open -a AwesomeCopy

What does this do? This resets window positions, dock placement, UI panel states, and internal sync/clipboard counters. Your custom settings like hotkeys, appearance preferences, and sync configuration are preserved.
